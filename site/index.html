Every offer in the file, and what the rules did with it

Sixteen rows become fourteen offers. An exact repeat is counted once. Two rows quoting different rents for the same suite stay together and are flagged, not settled. The same suite offered for storage only stays a separate offer. A blank field is never read as zero or as absent.

Input
sample-listings.csv, in an assumed column layout; row numbers count the header as row 1, as a spreadsheet does. Nothing here connects to a listings database; the file stands in for an export a broker would pull.
Rules
Filtering, grouping, costs and every sentence on the pages come from fixed rules over the current values. No AI model runs on this page. In a real workflow, a model would read your guidelines and example surveys; the arithmetic would stay in code, as here.
Output
The pages above, set for US Letter. The PDF for each budget step is printed from these same pages, so it always matches what you see.
